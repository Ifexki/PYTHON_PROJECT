# ONE-ROOF Python for Data Engineers — Lab Pack

## Purpose
These five labs progressively move from native Python manipulation to a small end-to-end Data Engineering pipeline.

## ONE-ROOF Assessment Principle
Correct code is not enough. You must understand:
- what the data represents;
- what business rule is being applied;
- what can fail;
- how to validate the result;
- when logic should be made reusable.

## Engineering Expectations
Use functions where they improve clarity, remove repeated logic, or give an important business rule a clear name.

Create your own Python module where reusable functions should live outside the main script.

Do not create functions, modules, or classes merely for decoration. Structure should solve a real readability, reuse, or maintainability problem.

## Lab Progression
1. Native Python collections and cleaning
2. Reusable functions and modules
3. File ingestion, validation, exceptions and logging
4. Pandas EDA, cleaning and transformation
5. End-to-end Python Data Engineering pipeline
