# Git / GitHub Submission Guide

After every lab:

```bash
git status
git add .
git commit -m "Complete Python Lab X - meaningful description"
git push
```

Before pushing:
- run your code;
- inspect `git status`;
- use `git diff` if needed;
- make sure no credentials or secrets are included;
- use a meaningful commit message.

Useful:
```bash
git diff
git log --oneline
```
